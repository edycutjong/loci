Open Loci

For judges · one page

Loci turns a photo of your own room into a memory palace for a list you must learn in order, then lights each stop back up as you say the list in the dark.

The path to click, receipts from a real run on the live site, how to reproduce them, and what Loci doesn't claim. Every number on this page links to where it came from.

The 30-second path

No sign-up, no key, nothing to install. Any browser; a phone works.

  1. 1

    Open Loci

    The home screen shows the method on a real room.

  2. 2

    Tap “Try it: 12 cranial nerves”

    A palace made in advance in an AI-generated student room opens at stop 1. No AI call, so no wait.

  3. 3

    Tap “Next stop” a few times

    Each stop is a real object in the photo, with a strange scene for its item.

  4. 4

    Tap “Lights out” (the moon) and type what you remember

    A right answer turns its stop green and lights that part of the room. occulomotor counts for Oculomotor; Optic at stop 5 stays dark.

  5. Read the result, then retry the misses

    First-try score, learning time and recall time. Every stop green brings the whole room back.

Stop 2 · Reproduce

Run it yourself. The real path needs no key.

The receipt runs against the live site, so the server's own keys do the AI calls. The tests are a separate, deterministic replay: they stub the AI and never stand in for the product.

The real runlive AI

git clone https://github.com/edycutjong/loci && cd loci
npm ci && npx playwright install chromium
# 9 palaces on the live site → public/judge/receipt-<date>.json
npm run receipt

About 3 minutes. Prints one line per palace and the totals. BASE_URL=http://localhost:5174 points it at your own dev server and keys.

The testsAI stubbed

# 99 unit tests and 60,000 generated answers, no network
npm test
# 29 browser checks; the AI helpers and the microphone stubbed
npm run e2e

The same commands CI runs on every push, plus tsc and the production build.

One call, with curl and jqlive AI

curl -s https://devpost-learn-loci.vercel.app/rooms/kos.jpg | base64 | tr -d '\n' | jq -Rs '{image: .}' \
  | curl -s https://devpost-learn-loci.vercel.app/api/anchors -H 'Content-Type: application/json' -d @- \
  | jq '{model, ms, tried, usage, objects: [.anchors[].label]}'

The student room's photo, straight to the object finder: which model answered, how long it took, which models it passed over and why, the tokens it used, and the objects it found.

Stop 3 · Honest limits

What Loci doesn't claim.

  1. Recall in one sitting, nothing more

    Loci shows a first-try score, learning time and recall time. It makes no claim about next week and has no spaced repetition.

  2. The receipt's rooms are AI-generated

    Real rooms are messier. When free-tier Gemini quotas run out, objects come from gemini-3.1-flash-lite, which draws looser boxes.

  3. Voice is Chrome and Edge only

    It uses the browser's own speech recognition. Automated Chrome can't open a microphone, so voice is tested with a stand-in recognizer; typing works everywhere.

  4. Your photo goes to an AI once

    Gemini, or DeepSeek if Gemini is busy, sees it to find objects; the server keeps nothing. A free-tier Gemini key lets Google use what it receives, so leave people and papers out.
