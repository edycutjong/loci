Two AI calls only: one finds objects and boxes in the photo, one writes scenes from object names, never the photo.

Everything that decides what is true runs as plain code in the browser: the route, and right or wrong.

A typo in a long word counts; swapped letters count as one slip; your own accepted answers count.

Short words must be exact, so Vitamin D never passes for Vitamin C. Spoken answers also match by sound: truck lear is Trochlear.
